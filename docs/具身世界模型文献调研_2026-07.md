## 1. 概念地图

### 1.1 术语混乱是这个领域的第一道门槛

Fudan 的 WAM 综述（*World Action Models: The Next Frontier in Embodied AI*, 2605.12090）专门用一节做术语切分，这本身说明问题的严重性。按其形式化：

| 范式 | 概率形式 | 说明 |
|---|---|---|
| **VLA** | `p(a \| o, l)` | 反应式策略，不显式建模世界演化 |
| **Action-conditioned WM** | `p(o' \| o, a)` | 纯预测器，不产生动作 |
| **Video Policy** | `p(o' \| o, l)` → 后处理提动作 | 生成视频计划，再用 IDM/流场反解动作 |
| **WAM** | `p(o', a \| o, l)` | **联合建模未来状态与动作** |

WAM 综述把 WAM 分两类：

- **Cascaded WAM**：显式因子分解 `p(o',a|o,l) = p(a|o',o,l)·p(o'|o,l)`。代表 UniPi、VLP、AVDC、TesserAct、NovaFlow、Vidar、LVP、π0.7。又分 **Explicit**（生成可见未来帧/流）与 **Implicit**（只用预测特征做条件，如 VPP、VILP）。
- **Joint WAM**：共享表征空间内共同优化状态预测与动作生成。按表征分 **Autoregressive** 与 **Diffusion-based**，后者再分 **Unified Stream** 与 **Multi-Stream**。

NTU 等的 *World Model for Robot Learning*（2605.00080）从**功能角色**切分：与策略耦合（Sec 3）、作为模拟器用于 RL 与评测（Sec 4）、机器人视频世界模型的能力演进（Sec 5）。两个综述视角互补：一个看"怎么接"，一个看"拿来干什么"。

OpenWorldLib（2604.04707）给出统一定义："以感知为中心、具备交互与长期记忆能力、用于理解和预测复杂世界的模型或框架"。

一篇立场论文 *Robots Need More Than VLAs & World Models*（2606.06556）提出**四类接口**框架，值得记住，因为它把"世界模型"放回整个系统里看：
- **数据接口**：无结构行为的自动标注——自动解析互联网视频、推断动作意图、加任务语义标签
- **本体接口**：人类运动到机器人动作的物理合规重定向
- **世界模型接口**：基于物理的 3D 推理——现有视觉世界模型多停留在像素预测，缺乏真正的 3D 空间与物理约束认知，下一代必须理解 3D 几何、接触力学与动力学
- **奖励接口**：仅通过观察视频/理解语言实时推断任务进展、识别失败并给出奖励

### 1.2 与"视频预测 vs latent JEPA"二分的关系

该二分是**表征空间**维度的划分。但实际设计空间至少三维正交（见 §2），二分法会漏掉几个重要方向——尤其是 **3D/4D 几何世界模型**（VGGT-World、StereoWorld、PAIWorld、RynnWorld-4D、μ0）、**流场作为动作表征**（FlowWAM）和**语言作为动作接口**（Qwen-RobotWorld）这三条线。

## 2. 研究方向图谱

### 维度 A：世界状态用什么表示（表征空间）

**A1. 像素/视频空间**

主流路线，继承视频生成基座（Wan、Cosmos、Veo、SANA）。优势：可视化、可复用互联网视频先验、可直接做数据生成与人工审查。代表：DreamGen（2505.12705）、Ctrl-World（2510.10125）、Veo Robotics（2512.10675）、OmniDreams（2606.03159）、GE-Sim 2.0（2605.27491）、Qwen-RobotWorld（2606.17030）、Xiaomi-Robotics-U0（2607.11643，38B 多模态自回归统一具身合成）、LingBot-World 2.0（2607.07534，无界交互时长 + 720p 60fps 实时 + agentic harness）。

代价明确：算力大量花在外观重建上。LaWAM（2606.15768）的对比数据很直观——LingBot-VA 单次策略推理 4482 ms，π0.5 只需 220 ms。DexWorldModel（2604.16484）把这个代价拆成三项：**冗余像素级重建、O(T) 显存增长、串行推理延迟**。

**A2. 语义 latent 空间（JEPA 系 / 冻结视觉基座特征空间）**

在预训练视觉编码器特征空间做预测，刻意丢弃像素细节。DINO-WM（2411.04983）；DINO-world（2507.19468，DINOv2 latent 空间通用视频世界模型，直觉物理强）；V-JEPA 2（2506.09985）与 V-JEPA 2.1（2603.14482，Dense Predictive Loss + Deep Self-Supervision）。

2026 年这条线在具身侧集中爆发：
- **DexWorldModel / CLWM**（2604.16484）：用 **DINOv3 特征作为生成目标**，把交互语义与视觉噪声解耦，获得强域泛化
- **RepWAM**（2606.13674）：训练**表征型视觉-动作 tokenizer**，把视觉输入压缩为对齐的视觉 token 与潜动作 token，在语义视觉-动作 latent 空间做世界动作建模
- **LingBot-VA 2.0**：明确"departing from reconstruction-focused VAEs"，改用语义视觉-动作 tokenizer
- **Lumo-2**（2607.11270）：latent world-action model，核心假设是**"动作生成质量由 latent 空间的几何结构决定"**
- **ω-EVA**（2606.09457）、**LaWAM**（2606.15768）、**InternVLA-A1.5**（2607.04988）、**GigaWorld-Policy-0.5**（2607.13960）

**A3. 几何 / 3D / 4D 空间**

- **VGGT-World**（2603.12655）：把冻结 VGGT 的 latent token 当世界状态，自回归预测其时间演化，**完全绕开视频生成**。动机是"视频世界模型把大部分容量花在光度细节上，预测却几何不一致"。
- **StereoWorld**（2603.17375）：相机引导的双目视频生成，内建几何理解。
- **PAIWorld**（2606.18375）：多相机 3D 一致性。诊断很清晰——现有多视角世界模型只是拼接 view token，缺显式跨视角通信与 3D 先验，导致跨视角物体漂移、深度不一致、纹理错位。主张两者**必须同时存在**：无几何引导的通信会退化为平凡捷径，无通信路径的几何先验无法跨视角传播。
- **RynnWorld-4D**（2607.06559）：主张 **RGB + 深度 + 光流（RGB-DF）** 的同步表征捕获场景的 4D 动力学，"表征空间显著更接近机器人所需的低层末端执行器动作，缩小世界预测与策略学习的间隙"。三分支架构 + 逐帧 3D RoPE，单一扩散过程内共同产出未来 RGB/深度/光流；配套 Rynn4DDataset 1.0（**2.544 亿帧**）；RynnWorld-4D-Policy 用 IDM 头单次前向消费内部 4D 表征，**绕开昂贵的多步去噪**。

**A4. 交互轨迹 / 流（trace / flow）空间**

- **μ0**（2606.13769）：预测物体、工具、手、接触区域等显著交互点的平滑 3D 轨迹（B-spline 控制点参数化），得到紧凑、跨具身无关的运动接口。冻结的 μ0 可与任意下游 action expert 配对，即使 action-free 预训练，所得策略也能与 π0 竞争。
- **FlowWAM**（2607.13017）：用**光流作为统一的、video-native 的动作表征**。洞察很漂亮——光流视频与 RGB 视频格式相同，可被同一个预训练视频生成器处理，且编码逐像素位移。双流扩散框架，policy 模式生成流做动作预测，world-model 模式用目标流引导未来视频生成。光流可从原始视频免标注抽取，因而能利用大规模无动作标签视频。RoboTwin 92.94%（Clean）/ 92.14%（Random）；WorldArena EWMScore 63.71，轨迹准确率相对提升 18.4%。

**A5. 多模态物理状态（尚未成形）**

WAM 综述明确指出：现有 WAM 几乎全在 RGB 模态预测未来，而接触密集操作最关键的物理信息（触觉分布、接触力、声学特征、材料柔顺性）在像素空间基本不可见——"世界模型恰恰在它最需要建模的物理交互处存在系统性盲区"。语料中的触觉/力工作（OSMO 触觉手套、TaF-VLA、FD-VLA）尚未与世界模型结合。该综述提出 **modality-adaptive prediction** 作为值得追求的能力。

### 维度 B：世界模型扮演什么角色（功能）

1. **训练时辅助目标 / 表征学习信号**——预测未来只用于塑造表征，推理时可关掉。VLA-JEPA、LaST0、WLA meta-query、InternVLA-A1.5 的 foresight token、GigaWorld-Policy 的 action-centered formulation。
2. **策略的条件输入（foresight conditioning）**——LaWAM 的 latent visual subgoal；MotionWAM 条件于中间去噪特征。
3. **想象中的 RL 环境**——Dreamer 系；机器人侧 WoVR、WMPO、World4RL、VLA-RFT。
4. **策略评测器**——Ctrl-World、Veo Robotics、GE-Sim 2.0、GigaWorld-1、WorldEval、WorldGym。**当前最成熟、最快落地**。
5. **数据生成器**——DreamGen 的 neural trajectories；RynnWorld-Teleop 的"数字遥操作"；RoVid-X；Qwen-RobotWorld。
6. **奖励/验证器**——GE-Sim 2.0 的 world judge；WMReward（2601.10553）用 latent WM 作奖励引导视频生成去噪；ω-EVA 把世界模型做成动作提案的**主动验证器**；SARM2 阶段感知奖励建模。

### 维度 C：预测与动作如何耦合（架构）

即 Cascaded / Joint 二分，详见 §3。

## 3. 模型架构设计

### 3.1 骨干与初始化

三种主流起点：

- **视频生成基座**（Wan / Cosmos / Veo / SANA）：物理动态先验强，语义规划弱。WLA（2606.05979）直言现有 WAM 依托双向扩散 Transformer，"仅预测底层视觉状态，缺失高层语义规划能力"。
- **VLM/MLLM 基座**：语义与指令理解强，物理动态弱。InternVLA-A1.5 指出现有统一设计的三个通病：**侵蚀预训练骨干的语义、异构目标间相互干扰、在像素空间从零学未来预测而没用上预训练视频生成器的动力学先验**。
- **自监督视觉基座**（DINOv2/v3、V-JEPA）：表征质量高、无需生成。LaWAM 在 DINO 特征空间训练 latent action model 再复用其 forward decoder；DexWorldModel 用 DINOv3 特征作生成目标。

一个值得注意的架构主张（LingBot-VA 2.0）：**因果预训练应当从零训起**，而非改造双向架构——因为适配双向架构常导致灾难性遗忘，而时间动力学本质上是严格因果的。

### 3.2 动作/条件注入机制

- **显式动作 token 拼接**（最简单，但动作与视觉 token 分布差异大）
- **layer-wise joint attention**（Qwen-RobotWorld：60 层 double-stream MMDiT，冻结 Qwen2.5-VL 语义与 video-VAE latent 逐层联合注意力）
- **语言作为统一动作接口**（Qwen-RobotWorld：统一 20+ 具身、500+ 动作类别，跨操作/驾驶/导航/人到机器人迁移）
- **latent action**（Motus；LaWAM 用 IDM 反解；RepWAM 的对齐视觉-动作 token；ABot-M0.5 的 intermediate latent action 作为"视频 latent 与具身特定控制之间的桥接动作空间"）
- **光流作为动作**（FlowWAM——因为它与 RGB 同格式，可被同一预训练生成器原生处理）
- **meta-query / foresight token 隐式耦合**（WLA：世界预测隐式影响动作生成，**推理时可关掉**，也可打开做 test-time scaling；InternVLA-A1.5：把未来预测重构为 **latent-querying 问题**，一小组可学的 foresight token 在冻结视频生成模型监督下把任务相关未来压缩成紧凑 latent code，策略由此继承世界模型动力学先验而**从不学习像素级生成**，推理时丢弃视频分支）
- **中间去噪特征条件**（MotionWAM：条件于视频世界模型的**中间去噪特征**而非完成的视频）
- **异构控制的 MoE 注入**（Worldscape-MoE：modality-aware control injection + 共享与控制特定专家 + 渐进式 MoE 调优；发现异构监督**相互增益而非干扰**）

### 3.3 潜空间的选择：重建 vs 语义——本领域最重要的一条实证线

**证据一（系统对照）**：*Reconstruction or Semantics?*（2605.06388）在 BridgeV2 上固定协议比较 6 种编码器，三轴评估（视觉保真、规划与下游策略、latent 表征质量）。结论：视觉保真度单独**不足以**作为选型依据。VAE、Cosmos 这类重建编码器像素分数强，但 V-JEPA 2.1（策略上整体最强）、Web-DINO、SigLIP 2 这类语义编码器在另外两轴上、在所有模型规模下普遍更优。

**证据二（控制变量的世界目标消融——本调研中最有价值的单篇实证）**：**EgoWAM**（Georgia Tech）固定策略骨干、动作头、数据配比，**只改变世界预测目标**，对比 Pixel / DINO / 3D motion flow，在三个真实双臂任务上评估人到机器人迁移：

- WAM 联合训练比行为克隆更能随 in-the-wild 第一视角人类数据规模化
- **像素预测迁移很弱**
- **DINO 把 OOD 物体与场景泛化提升最多 4×**
- **3D flow 把域内性能提升 20–30%**

其假设也说得很清楚：有效的世界目标应当**抽象掉外观、捕获与智能体无关的物理效应、把相机运动与环境变化分离**。这几乎是对"latent 世界模型为什么有用"的教科书式回答，也正面回应了 WAM 综述呼吁的"受控消融"。

**证据三（架构主张）**：Lumo-2 的核心假设——动作生成质量由 latent 空间的几何结构决定；标准的重建式动作 tokenization 目标诱导出偏向低层信号保真的表征，**重建质量与下游控制性能之间会错位**。其方案是多阶段模态预对齐：动作表征渐进对齐到 latent 世界动力学、视觉、语言。RepWAM 与 LingBot-VA 2.0 是同一判断的两个独立实现。

**反向证据（必须列出）**：GenCeption（Google DeepMind, 2607.09024）主张大规模文生视频是强大的视觉预训练范式，并报告**视频生成预训练骨干在可比设置下优于 V-JEPA 与 Video MAE**（深度、法向、相机位姿、指代分割、3D 关键点等感知任务）。同类结论还有 *Image Generators are Generalist Vision Learners*（2604.20329）。

**如何调和**：注意评测任务不同——GenCeption 评的是**稠密感知任务**，而 2605.06388 与 EgoWAM 评的是**策略/控制**。目前的证据支持这样一个更精细的结论：**生成式预训练在需要稠密几何/外观细节的感知任务上更强；语义 latent 在需要抽象掉外观、保留因果动力学的控制任务上更强。** 这两件事不矛盾，但至今没有工作把它们放在同一实验中讲清楚——这本身是一个明确的研究缺口。

### 3.4 效率：WAM 落地的第一约束

WAM 综述称之为"latency tax"：DreamZero 通过算法加速与底层 CUDA 优化把 WAM 推理推到 ~7Hz，仍显著落后于非生成式 VLA 的 50Hz 标准。

| 方法 | 手段 | 效果 |
|---|---|---|
| Dreamer 4 (2509.24527) | shortcut forcing + 高效 transformer | 单 GPU 实时交互推理 |
| LaWAM (2606.15768) | latent visual subgoal 替代重建视频 | 187 ms/动作块，较像素 WAM 低 **24×** 延迟；LIBERO 98.6%、RoboTwin 91.22% |
| WLA (2606.05979) | AR 骨干 + 推理时禁用世界预测；World Expert 只预测**单帧**（其 LIBERO 消融显示多帧预测成功率显著低于单帧，作者推测过密的视觉监督会减慢收敛） | 2B 激活参数、RTX 5090 上 **40 ms** |
| ω-EVA (2606.09457) | 消费推理全在 latent 特征空间 | ~1.2B 参数，无额外机器人数据预训练 |
| MotionWAM (2606.09215) | 条件于中间去噪特征 | 实时人形全身 loco-manipulation |
| GE-Sim 2.0 (2605.27491) | 加速框架 + 推理时最高 4× 跳帧 | 单 H100 上 2.3 s 生成 25 帧 rollout |
| DexWorldModel (2604.16484) | **Dual-State TTT Memory**（长时程严格 O(1) 显存）+ **Speculative Asynchronous Inference**（把部分扩散去噪掩藏在物理执行之后） | 阻塞延迟降低约 **50%** |
| Next Forcing (2606.11187) | MCP 模块推理时保留，与当前块并行预测下一块 | **2×** 推理加速 |
| LingBot-VA 2.0 | 稀疏 MoE 骨干 + 增强异步推理（预测未来 latent 与动作执行并行，每次 rollout 用学习的前向动力学在最新观测上重新接地） | 实时闭环控制 |
| GigaWorld-Policy-0.5 (2607.13960) | action-centered：训练用未来视觉动态，**推理只解码动作**；Mixture-of-Transformers 分离视觉动态专家与动作专家 | 本地 **RTX 4090 上 85 ms** |
| RynnWorld-4D-Policy | IDM 头单次前向消费内部 4D 表征 | 绕开多步去噪 |
| RynnWorld-Teleop (2607.06558) | 流式自回归蒸馏，压缩为单次前向 | 单 H100 **40+ FPS** 实时交互生成 |

WAM 综述的深层问题值得记住：**"下游控制到底需要多少预测保真度？"** 若性能增益在远低于完整扩散合成质量处就饱和，目标就不该是"把高保真预测做得更快"，而是"找到给定任务的最小充分世界模型"，即 **task-adaptive predictive fidelity**。

**注意 2026 年 7 月这批工作已经在事实上回答了这个问题**：GigaWorld-Policy-0.5、InternVLA-A1.5、WLA 都采用"训练时用世界建模、推理时不生成"的设计并取得 SOTA——这强烈暗示**世界建模的主要价值在训练梯度，而非推理时的显式想象**（详见 §8.3）。

### 3.5 结构一致性：3D、多视角与 4D

PAIWorld（跨视角几何注意力 + Geometric RoPE）、VGGT-World（预测几何基座特征）、RynnWorld-4D（RGB-DF 三分支 + 逐帧 3D RoPE）、Xiaomi-Robotics-U0（首个支持跨多机器人具身的高质量多视角场景生成，并引入结构化可控的 embodied transfer 做细粒度编辑同时保持多视角一致性与交互动力学）。

另有一条不依赖显式 3D 输入的路线：**Spatial Forcing**（2510.12276）——隐式空间表征对齐，不用深度图/点云就迫使 VLA 发展空间理解能力，规避传感器噪声、硬件异构与深度覆盖不全的问题。

### 3.6 学习粒度与训练-测试一致性

- **WALL-WM**（2606.01955）的**粒度错配**诊断：语言描述语义目标与事件，视觉通过连续场景动态演化，动作在控制级时间尺度运行——三者塞进同一定长预测窗口，会把 VLA 训练退化为短时程相关性拟合，还可能用 chunk 捷径覆盖预训练视觉-语义先验。方案：以**语义事件**为原子学习单元 + 事件级 caption + 聚类平衡采样 + 变长执行块。
- **ABot-M0.5**（2607.00678）针对移动操作提出**三层对齐**：时间粒度（intermediate latent action 作桥接动作空间）、动作空间（双层 MoT 解耦模态表征与异构动作子空间如底盘移动 vs 手臂操作）、训练-测试一致性（**dream-forcing**：在模型预测的视频上渐进训练逆动力学，改善自回归预测时的 train-test 对齐与鲁棒性）。

## 4. "Forcing 家族"：训练目标的演化主线

这批语料里"*-Forcing"已经形成一个可辨识的方法族，梳理出来对理解领域主线很有帮助。它们解决的是同一个根问题的不同侧面：**训练时的条件分布与推理时的条件分布不一致**（exposure bias），以及由此导致的误差累积。

| 名称 | 解决什么 | 做法 |
|---|---|---|
| Teacher forcing（基线） | — | 训练时以**真实**历史帧为条件；推理时只能以自己生成的帧为条件 → 误差逐帧累积、长 rollout 漂移 |
| Diffusion forcing | 训练-推理 gap | 给不同帧加不同强度噪声，让模型习惯"不完美历史"；但人工噪声≠真实生成误差分布 |
| **Self forcing** | 训练-推理 gap（彻底版） | 训练时就自回归生成前面的帧，以**自己生成的帧**为条件学下一帧，配合分布匹配损失对整段生成施加监督。代价是训练时要真做 rollout |
| **Shortcut forcing**（Dreamer 4, 2509.24527） | 速度 + 精度 | 使世界模型在单 GPU 上实现实时交互推理，同时准确预测复杂环境中的物体交互 |
| **Next Forcing**（2606.11187） | 收敛慢、高帧率下精度低、推理慢 | 借鉴 LLM 的 multi-token prediction，引入 **multi-chunk prediction (MCP)**：轻量辅助模块同时对多个未来时间尺度（next₁/next₂/next₃ chunk）去噪，形成跨预测深度的**因果链**，近未来预测告知远未来预测，为主模型提供稠密多尺度时间监督。50 fps 下 5k 步时相对 LingBot-VA **+93.1%**，收敛快 **2.3×**；RoboTwin **94.1/93.5**（Clean/Random）；推理保留 MCP 模块可并行预测下一块，**2× 加速**；PhyWorld（物理定律遵从基准）显著提升；通用视频预训练 FVD 降低 **>50%** |
| **Dream forcing**（ABot-M0.5, 2607.00678） | IDM 的训练-测试错配 | 在**模型预测的视频**上渐进训练逆动力学，而非只在真实视频上 |
| **PhysisForcing**（2606.28128） | 物理不合理 | 把监督集中到物理信息丰富的区域：pixel-level trajectory alignment loss（用参考点轨迹监督 DiT 特征）+ semantic-level relational alignment loss（把 DiT 特征与冻结视频理解编码器抽出的区域间关系对齐） |
| **Spatial Forcing**（2510.12276） | 缺乏 3D 空间感 | 隐式空间表征对齐，不依赖显式 3D 输入 |

**读法**：前四个处理的是"时间维度的一致性"，后三个处理的是"内容维度的正确性"。Next Forcing 是目前时间维度上最系统的方案；PhysisForcing 是内容维度上最实证化的方案。**两者尚未被组合过——这是一个明确的低垂果实。**

## 5. 数据处理与数据生态

### 5.1 数据金字塔

*Data Pyramid for Embodied Manipulation*（2607.24744）把具身数据生态组织为五层，围绕**可扩展性 vs 机器人对齐度**的张力，并按数据质量、多样性、可复用性、物理保真度刻画每一层：

1. 真机数据（robot alignment 最高、scalability 最低）
2. UMI 式数据（便携夹爪）
3. 第一/第三视角人类视频
4. 仿真数据
5. 通用视觉-语言数据（scalability 最高、alignment 最低）

WAM 综述的划分基本一致（遥操作 / 便携人类演示 / 仿真 / 互联网第一视角视频）。核心矛盾：最有用的监督（动作标签）最稀缺，最丰富的数据（视频）无动作标签。μ0 称之为"根本性的数据悖论"。

### 5.2 一个重要的实证结论：人类第一视角视频可以**超过**真机数据

**HumanScale**（2606.20521）在固定后训练与验证协议下，系统比较第一视角人类视频与遥操作真机轨迹作为具身基座模型的预训练数据源。结论出人意料：**经过精心设计的过滤与标注流水线后，第一视角数据不只是可行替代，还能带来更优性能——相同预训练数据量下，用第一视角数据预训练的模型在真机动作预测上验证损失低 24%。**

这部分回答了 WAM 综述提出的数据配比开放问题，但也把问题推进了一步：**决定性因素可能不是数据源本身，而是过滤与标注流水线的质量。**

EgoWAM 从另一角度补充：行为克隆会把可迁移内容（物体、场景、任务语义）与不可迁移因素（人类形态、头部运动、行为风格）纠缠在一起，而 WAM 联合训练（要求策略同时预测动作与场景演化）提供了更好的训练信号，并且**随人类数据规模化得更好**。

### 5.3 打通无动作标签数据的四条技术路线

- **伪动作 / 潜动作**：从相邻帧用 IDM 反解。Motus、LaWAM、RepWAM、ABot-M0.5。DreamGen 从生成的 neural trajectories 自动抽取伪动作。
- **中间接口表征**：μ0 的 3D 交互轨迹（TraceExtract 数据引擎：DINOv2 聚类选语义关键点 → 提升到全局对齐 3D → 运动片段与分层语言 caption 关联）；FlowWAM 的光流（可从原始视频免标注抽取）。
- **语言作为动作接口**：Qwen-RobotWorld。
- **测试时吸收**：**WAM-TTT**（2607.06988）——把人类视频通过自监督视频预测吸收进冻结 WAM 内部的轻量自适应记忆（TTT fast weights），配合元训练阶段用配对人-机数据与 key–value 记忆重建目标对齐；部署时**只需无标注人类视频，无需重定向、机器人动作或人侧标注**。这是把"人类视频→机器人行为"从训练问题变成了部署时问题，思路很新。

### 5.4 数据引擎与开放资源

- **RoVid-X**（2601.15282）：四阶段流水线，**400 万**标注视频片段，数千任务，附物理属性标注，称最大开源机器人视频生成数据集。
- **Rynn4DDataset 1.0**（2607.06559）：**2.544 亿帧**，覆盖第一视角人类与机器人操作视频，含高质量深度与光流伪标签。
- **EWK**（Qwen-RobotWorld）：**860 万**视频-文本、2 亿+帧，含动作-语言映射，20+ 具身、500+ 动作类别。
- **GigaWorld-1**（2607.02642）：**12,000+ 小时**训练数据；分析了 **324,000** 个世界模型模拟 rollout、7 个视频世界模型、4 种动作表征范式。
- **Open-AoE**（Ant Group）：开源第一视角操作数据集与工具链，覆盖从手机采集到模型训练的全流程。
- **GE-Sim 2.0** 在数千小时真实机器人数据上重训，涵盖遥操作、接触密集交互、**在机策略部署**——最后一项是闭环数据飞轮的关键。
- **RynnWorld-Teleop**（2607.06558）提出**数字遥操作**范式：用生成式世界模型替代真实机器人，操作者的手部姿态流驱动机器人中心的生成式世界模型从单张参考图合成高保真第一视角视频；记录的姿态流作为**具身无关的动作标签**，可通过标准重定向迁移到任意目标机器人，产出完整状态-动作轨迹。纯用其生成数据训练的策略实现有效零样本 Sim2Real；用其增广真实数据集持续提升成功率。

### 5.5 训练策略

- **渐进式课程**：Qwen-RobotWorld 的 General+Expert 两阶段；MotionWAM 三阶段渐进适配；Worldscape-MoE 的渐进式 MoE 调优（支持持续扩展到新动作模态）；Lumo-2 的多阶段模态预对齐。
- **两阶段简化配方**：VLA-JEPA 主张 JEPA 预训练 + 动作头微调，避免既有潜动作流水线的多阶段复杂性。
- **混合目标预训练**：GigaWorld-Policy-0.5 采用 AC-WM（动作条件世界建模）与 WAM 混合训练，强化视觉动态与动作的耦合并提升动作表征的下游可迁移性。
- **在线数据注入**：DexWorldModel 的 EmbodiChain 在训练中注入无限流的物理接地轨迹，作者称之为 "Efficiency Law"。
- **自动化研究流水线**：GigaWorld-Policy-0.5 用基于 agent 的 **AutoResearch** pipeline 系统搜索训练配置——这是"用 agent 做超参/架构搜索"首次出现在这个领域的技术报告里。
- **大规模训练基建**：WALL-WM 用 Muon 优化器的大规模预训练基建。

### 5.6 数据配比：仍是公认的未解问题

WAM 综述提出应把人类视频的价值理解为**可迁移知识的层级**：(1) 低层物理先验（物体恒存、重力约束）；(2) 中层因果动力学；(3) 高层任务逻辑（与具身无关的时序依赖）。据此提出两个前沿：从信息论视角做数据配比，以及 **embodiment-aware filtering**——选择性蒸馏通用物理规律，同时隔离/抑制与目标机器人运动学不兼容的行为。HumanScale 与 Data Pyramid 是这个方向上最新的两块拼图，但都还没给出可操作的配比公式。

## 6. 评测

### 6.1 三层评测结构（WAM 综述）

**世界建模能力**：
- *视觉保真度*：PSNR/SSIM、LPIPS/DreamSim/DINO 相似度、FVD
- *物理常识*：VideoPhy（固-固、固-流、流-流交互，二元人工标注）；PhyGenBench/PhyGenEval（VLM+LLM 自动化，分解为关键物理现象检测、物理顺序验证、整体自然度）；PhyWorld
- *动作合理性*：合成转移是否含足够信息可被反解为可执行控制信号

**动作策略能力**：下游任务成功率。

**核心批评**：当前评测严重解耦。世界建模用 PSNR/FVD 衡量，捕捉视觉可信度但忽略物理正确性——**允许"无支撑物体悬浮""流体违反重力"的视频拿高分**；动作生成则只看任务成功率。

### 6.2 从开环到闭环：评测范式的转折

**World-in-World**（2510.18135）是第一个把世界模型放进闭环环境评测的开放平台，提供统一在线规划策略与标准化 action API，以任务成功率为主指标。三个"意外"发现极具指导意义：

1. **视觉质量本身不保证任务成功——可控性更重要。**
2. **用动作-观测数据做后训练，比升级预训练视频生成器更有效。**
3. **增加推理时计算能显著提升闭环表现。**

**GigaWorld-1 / WMBench**（2607.02642）把这条线推向系统化：从真机遥操作数据构建基准，分析 324K 世界模型模拟 rollout、7 个视频世界模型、4 种动作表征范式，明确针对"**什么属性让一个世界模型能可靠地评测策略**"这一此前理解很差的问题。

**WR-Arena**（2603.25887）从三维度评测：动作模拟保真度（遵循多步语义指令、生成多样反事实 rollout）、长时程预测、模拟推理与规划（通过模拟、比较、选择备选未来支持目标导向推理）。结论是当前模型与人类级假设推理之间存在实质差距。

**RBench**（2601.15282）：5 个任务域、4 种具身，评估任务级正确性与视觉保真度，含结构一致性、物理合理性、动作完整性等可复现子指标；评测 25 个模型，与人工评价 Spearman 相关系数 **0.96**。

**WorldArena**：GE-Sim 2.0 以仅 2B 参数登顶公开榜单；FlowWAM 取得最佳 EWMScore 63.71；Xiaomi-Robotics-U0 在具身视频生成上排名第一；PhysisForcing 在其 action-planner 协议下报告闭环成功率 16.0%→24.0%。

其余基准：EWM-Bench、DreamGen Bench、WorldModelBench、PBench、PAI-Bench、EZS-Bench、RoboTwin-IF。基准生态已相当碎片化。

### 6.3 仿真基准与鲁棒性评测

- **LIBERO / LIBERO-Plus（7 类扰动）/ LIBERO-Pro / LIBERO-X**
- **RoboTwin 2.0 / RoboTwin 2.0-Plus**（双臂 Aloha-Agilex 扰动协议）
- **SimplerEnv、RMBench、VLMbench**
- **RoboDojo**（2607.04434）：统一 sim-and-real 基准——仿真 42 任务 / 5 个维度（泛化、记忆、长时程、精度、开放），真机 18 任务 / 3 种具身，强调可复现（布局、光照、机器人设置）
- **GM100**（2601.11421）：100 个细节导向任务评测具身 agent

**关键对照实验**（2603.22078，华为）：在 LIBERO-Plus 与 RoboTwin 2.0-Plus 上比较 SOTA VLA 与 WAM 的鲁棒性：
- WAM 对噪声、光照、布局扰动普遍鲁棒（LingBot-VA 在 RoboTwin 2.0-Plus 达 74.2%，Cosmos-Policy 在 LIBERO-Plus 达 82.2%），作者认为至少部分归因于世界模型骨干继承的时空先验
- π0.5 这类经典 VLA、以及 Motus / VLA-JEPA 这类混合方法**可以达到相当甚至更优的鲁棒性，但通常需要精心策划的多样化数据集和/或预训练阶段的显式动态预测目标**
- 部分引入视频动态学习的混合方法表现中间水平，说明**视频先验如何整合**很关键

**解读要谨慎**：这不能证明"WAM 天生更泛化"，而是说明 WAM 用更简单的具身预训练达到了 VLA 需要复杂数据工程才能达到的鲁棒性——**这是数据效率优势，不是能力上限优势。**

### 6.4 真机评测

- MotionWAM：Unitree G1 上 9 个真实任务，整体成功率超同等演示微调的 VLA 基线 **30%+**，并能执行上下身解耦策略无法完成的任务驱动足部交互
- Xiaomi-Robotics-U0：把 π0.5 在挑战性真实操作任务上的 OOD 成功率从 **36.9% 提升到 63.2%**
- DexWorldModel：报告"前所未有的零样本 sim-to-real 迁移"，优于明确在真实数据上微调的基线
- RynnWorld-4D-Policy：真实双臂灵巧操作 SOTA，尤其在需要空间精度与时间协调的任务上
- LaWAM、VLA-JEPA、WLA、WALL-WM、Lumo-1/2、GE-Sim 2.0、WoVR 均报告真机结果

### 6.5 用世界模型做评测（评测本身的自动化）

Ctrl-World 直击痛点：严格评测需大量真机 rollout，系统性改进需带专家标注的纠正数据，两者都慢、贵、难扩展。Veo Robotics 进一步证明视频模型可覆盖**策略评测的全谱**——从名义性能，到 OOD 泛化，再到物理与语义安全性探测。GE-Sim 2.0 的 world judge 提供机器可验证的成功信号。GigaWorld-1 则回答"什么样的世界模型才配当评测器"。

**判断**：这是世界模型目前**投入产出比最高**的应用方向。

| 表征预训练 | V-JEPA 2/2.1、DINO-world、VLA-JEPA、μ0、RepWAM、EgoWAM | ★★★★☆ |
| 策略条件/foresight | LaWAM、VPP、WLA、InternVLA-A1.5、GigaWorld-Policy、MotionWAM | ★★★★☆ 快速上升 |
| 自动驾驶闭环仿真 | OmniDreams | ★★★★☆ |

| 测试时行为引导 | WAM-TTT | ★★☆☆☆ 很新 |

两个值得单独提的：

**WMReward**（2601.10553）把提升视频生成物理合理性当作**推理时对齐问题**，用 latent 世界模型（V-JEPA 2）的物理先验作为奖励搜索并引导多条候选去噪轨迹，通过 test-time compute scaling 提升表现——ICCV 2025 Perception Test PhysicsIQ Challenge 最终分 **62.64%，第一名，超此前 SOTA 7.42%**。这是"latent 世界模型可以给像素世界模型当裁判"的实证。

**WoVR**（2602.13977）正面处理"世界模型做 RL 模拟器"的核心障碍——闭环想象 rollout 不可避免地出现幻觉与长时程误差累积，这些误差不只降低视觉保真度，还**通过提供不可靠的学习信号误导策略优化**。WoVR 的策略是**不假设世界模型忠实**，而是显式规制 RL 如何与不完美的想象动力学交互：可控的动作条件视频世界模型提升 rollout 稳定性、**Keyframe-Initialized Rollouts** 降低有效误差深度、**世界模型-策略协同演化**维持二者对齐。结论是"当幻觉被显式控制时，世界模型可以作为 RL 的实用模拟器"。

## 8. 隐世界模型 / WAM 的优势分析

### 8.1 六条优势（按证据强度排序）

**① 计算效率——证据最强、最无争议**

LaWAM 较像素空间 WAM 低 **24×** wall-clock 延迟（187 ms/动作块）；WLA-0 在 RTX 5090 上 **40 ms**；GigaWorld-Policy-0.5 在消费级 RTX 4090 上 **85 ms**；ω-EVA 仅 ~1.2B 参数且无需额外机器人数据预训练。对比像素 WAM 的 4482 ms（LingBot-VA）与 VLA 的 220 ms（π0.5），是数量级差距。DexWorldModel 还额外解决了 O(T) 显存问题（Dual-State TTT Memory 保证严格 O(1)）。

**② 世界预测目标的受控消融直接支持 latent——本调研中最硬的证据**

EgoWAM 固定一切、只换世界目标：**像素预测迁移很弱；DINO 把 OOD 物体/场景泛化提升最多 4×；3D flow 把域内性能提升 20–30%。**

**③ 表征质量对策略更有利——有系统性实证**

2605.06388 固定协议对照：语义编码器（V-JEPA 2.1 最强、Web-DINO、SigLIP 2）在规划/下游策略性能与 latent 表征质量两轴上、在所有模型规模下普遍优于重建编码器，尽管后者像素分数更高。Lumo-2 从架构侧给出同样判断：重建式 tokenization 目标诱导偏向低层信号保真的表征，**重建质量与下游控制性能会错位**。

**④ 抽象化本身就是一种物理归纳偏置**

在 latent 空间预测意味着模型自行决定"什么值得预测"。EgoWAM 把有效世界目标的三条属性说得最清楚：**抽象掉外观、捕获与智能体无关的物理效应、把相机运动与环境变化分离**。DINO-world 展示对直觉物理的强理解；WMReward 用 V-JEPA 2 的物理先验纠正视频生成器，反向印证 latent 模型的物理先验质量。

**⑤ 泄漏鲁棒与外观不变性——需要正确设计才能获得**

VLA-JEPA（2602.10098）的诊断很准：现有潜动作目标"常常学到错误的东西"——仍锚定像素变化而非动作相关的状态转移，因而易受外观偏置、无关运动、信息泄漏影响。解法是 **leakage-free state prediction**：target encoder 从未来帧产生 latent 表征，student 路径只看当前观测，未来信息**仅作监督目标、绝不作为输入**。DexWorldModel 用 DINOv3 特征作生成目标"解耦交互语义与视觉噪声"，是同一思路的另一实现。

**注意这是有条件的优势**：latent ≠ 自动获得不变性，设计错了照样学到像素捷径。

**⑥ 跨具身可迁移**

μ0：action-free 预训练 + 冻结复用，3D trace 作跨具身接口，所得策略可与有动作监督预训练的 π0 竞争。ABot-M0.5 的 intermediate latent action 明确定位为"视频 latent 与具身特定控制之间的桥接动作空间"。WAM-TTT 更进一步，把人类视频的行为引导做成部署时的记忆吸收，完全绕开重定向。

### 8.2 四条代价（必须诚实面对）

**① 可解释性与可审查性丧失**
像素世界模型的一大隐性价值是人能直接看出它错在哪。latent rollout 无法人工审查，调试与失效归因困难。这也是为什么"用世界模型做策略评测"这条最成熟的应用线几乎全是像素路线（Ctrl-World、Veo、GE-Sim 2.0、GigaWorld-1）——**评测需要人看得懂**。

**② 无法直接用于数据生成**
latent rollout 不能拿去训练需要图像输入的其他模型，除非配解码器。RynnWorld-Teleop 这类数字遥操作、DreamGen 这类合成数据引擎都必须是像素路线。

**③ 感知任务上生成式预训练可能更强**
GenCeption（DeepMind）报告视频生成预训练骨干在可比设置下优于 V-JEPA 与 Video MAE（深度、法向、相机位姿、指代分割、3D 关键点）。这说明 latent 的优势是**任务相关的**，不是普遍的。

**④ 接地质量的开放疑问**
WAM 综述原话值得逐字记住："latent-only 表征能在多大程度上维持与生成式方法同等的接地质量，仍然是一个至关重要的开放问题。"

### 8.3 一个关键的观察：世界建模的价值可能主要在训练梯度

WAM 综述指出：**世界建模在某些 WAM 中的主要效用可能来自训练时提供的辅助梯度，而非推理时显式生成未来帧**——一些框架证明推理时移除未来预测头并不必然降低下游控制性能。

**2026 年 7 月这批工作把这个观察变成了事实上的主流设计**：

- **WLA**：meta-query 让世界预测隐式影响动作生成，推理时可关闭（也可打开做 test-time scaling）
- **InternVLA-A1.5**：foresight token 在冻结视频生成模型监督下压缩未来，策略继承世界模型动力学先验而**从不学习像素级生成**，**推理时丢弃视频分支**
- **GigaWorld-Policy-0.5**：action-centered formulation——训练用未来视觉动态，**推理只解码动作**
- **DexWorldModel**：Speculative Asynchronous Inference 把部分去噪掩藏在物理执行之后（承认想象的实时价值有限）

**战略含义**：如果世界模型的价值主要在训练信号，那么"更快的世界模型"这个目标可能是错的，正确的目标是"**更好的世界建模训练目标 + 推理时零成本**"。这也解释了为什么 latent 路线在 2026 年迅速成为主流——它天然与这个方向对齐。

**但反例也存在**：ω-EVA 的 Envision–Verify–Act 循环、World-in-World 发现"增加推理时计算显著提升闭环表现"、WMReward 的 test-time scaling，都表明推理时想象仍有独立价值。**这个张力尚未被解决，而它恰恰是最值得做的实验之一。**

## 9. 如果要做：开展路径与优化手段

### 9.1 先做定位选择

**Q1：世界模型是训练时的辅助信号，还是推理时的活跃组件？**
- 训练时辅助 → VLA-JEPA / WLA / InternVLA-A1.5 / GigaWorld-Policy 路线：推理零开销，工程风险低，2026 H2 已是主流，但也因此**竞争激烈、增量空间被压缩**
- 推理时活跃 → ω-EVA / WMReward 路线：能做反事实验证与提案修正，需解决延迟，但**理论空间更大且人少**

**Q2：latent 空间做什么用？**
- 给策略当条件（subgoal）→ LaWAM
- 给策略做提案验证（闭环反馈）→ ω-EVA
- 做跨具身接口 → μ0 / ABot-M0.5
- 做规划中的 rollout（MPC/CEM）→ DINO-WM
- 做 RL 模拟器 → WoVR（注意必须显式处理幻觉）

### 9.2 一条风险收益比较好的路线

**Phase 0：基线复现与选型（2–4 周）**
- 冻结基座选型：直接采信 2605.06388 与 EgoWAM 的结论，起点用 **V-JEPA 2.1 或 DINOv3**，对照组 SigLIP 2 / VAE / 3D flow
- 建立三轴评估脚手架（视觉保真、下游策略、latent 表征质量），从第一天起就不看单一指标
- 环境：LIBERO-Plus + RoboTwin 2.0(-Plus)（有 2603.22078 的对照数据可比）+ RoboDojo（sim-real 统一）

**Phase 1：动力学预训练**
- 目标函数：leakage-free 的动作条件 latent 预测（VLA-JEPA 式），务必确保 student 路径看不到未来
- 动作条件化：优先用真实动作标签的机器人数据建立 `∂s'/∂a` 的因果结构；无标签视频用 latent action / 3D trace / 光流接口接入
- 时间一致性：直接上 **Next Forcing 式的 multi-chunk prediction**（多尺度稠密时间监督 + 推理时并行加速），而不是先做 teacher forcing 再补救
- **关键设计决策**：预测 horizon 与抽象层级。WLA 的 LIBERO 消融（多帧预测成功率显著低于单帧）提示不要一开始就追长 rollout——过密的视觉监督可能是负担而非收益
- **anti-shortcut 措施**：随机相机抖动、背景替换、无关运动干扰作为增强，直接测试表征是否不变（EgoWAM 的三条属性可直接做成检查项）

**Phase 2：诊断而非只看成功率（决定研究价值的一步）**
至少做三项探针：
1. **线性可解码性**：从 latent 能否线性解出物体位置/姿态/接触状态？这直接回答"学到了什么物理量"
2. **动作 Jacobian 正确性**：扰动动作，看 latent 变化方向是否符合真实因果。这是区分"统计续帧"与"因果动力学"的核心判据
3. **多步 rollout 误差累积曲线**：误差 vs 步数，与像素基线对比

ω-EVA 已在做"latent diagnostics"验证动作条件的未来结构有意义，这个思路值得系统化。

**Phase 3：与策略耦合**
- 先做最简单的 foresight conditioning（LaWAM 式），确立收益基线
- 再做 Envision–Verify–Act 闭环（ω-EVA 式），衡量"主动验证"相对"被动条件"的增量
- **消融必做**：把世界头在推理时关掉，看性能掉多少。这决定了你的世界模型是"训练信号"还是"推理组件"，审稿人一定会问

**Phase 4：效率与真机**
- 目标锚定 50Hz（VLA 标准）。参考实现：GigaWorld-Policy-0.5 的 MoT 分离 + action-only decoding（85 ms @ RTX 4090）、LingBot-VA 2.0 的异步推理 + 前向动力学 re-grounding、DexWorldModel 的 Speculative Asynchronous Inference
- 真机验证不可省略——仿真鲁棒性与真机鲁棒性的相关性在这批文献里从未被系统验证过

### 9.3 具体优化手段清单

**训练目标**
- Leakage-free 预测（VLA-JEPA）
- Dense predictive loss + deep self-supervision（V-JEPA 2.1）
- Multi-chunk prediction 的稠密多尺度时间监督（Next Forcing）
- Dream forcing：在模型预测视频上训 IDM（ABot-M0.5）
- 物理信息区域的定向监督：轨迹对齐 + 关系对齐（PhysisForcing）
- AC-WM 与 WAM 混合预训练（GigaWorld-Policy-0.5）

**表征**
- 语义 latent > 重建 latent（2605.06388、EgoWAM、Lumo-2、RepWAM、LingBot-VA 2.0 一致）
- 多阶段模态预对齐：动作 → latent 世界动力学 → 视觉 → 语言（Lumo-2）
- 几何/4D latent 作补充：RGB-DF（RynnWorld-4D）、几何基座特征（VGGT-World）
- 3D trace（μ0）或光流（FlowWAM）作跨具身接口
- 事件级而非定长 chunk 的时间抽象（WALL-WM）

**架构**
- 推理时可关闭的世界头（WLA meta-query / InternVLA-A1.5 foresight token）
- MoT/MoE 分离视觉动态专家与动作专家（GigaWorld-Policy-0.5、ABot-M0.5、Worldscape-MoE）
- 条件于中间去噪特征而非完整生成（MotionWAM）
- 因果预训练从零训起而非改造双向架构（LingBot-VA 2.0）
- O(1) 显存的 TTT 记忆（DexWorldModel）
- 跨视角几何注意力（PAIWorld），若是多相机设置

**推理**
- Test-time compute scaling（World-in-World 发现 3；WMReward 已验证）
- 异步/投机推理把去噪掩藏在执行之后（DexWorldModel、LingBot-VA 2.0）
- Task-adaptive predictive fidelity：按任务难度动态调节预测深度与分辨率
- 测试时用人类视频引导（WAM-TTT）

### 9.4 差异化机会（我认为最值得做的四个空白）

1. **把 PhysisForcing 的物理定向监督迁移到 latent 空间。** 目前物理一致性的显式注入几乎全在像素域做（需要点轨迹参考）。在语义 latent 空间如何定义"物理信息丰富的区域"、如何构造关系对齐损失，结构清晰但尚未被做。

2. **Next Forcing × PhysisForcing 的组合。** 前者解决时间一致性，后者解决物理正确性，两者正交且都已单独验证有效，但从未被组合。

3. **多模态 latent 世界模型（视觉 + 触觉/力）。** WAM 综述明确指出这是"largely unexplored frontier"，且 latent 路线天然适合融合异构模态（不需要为触觉设计"生成器"，只需在联合 latent 里预测）。语料里已有触觉硬件（OSMO 开源触觉手套）与力感知 VLA（TaF-VLA、FD-VLA），但**尚无人把它们接进世界模型**。这可能是 latent 相对像素路线的**结构性优势**，而非仅效率优势。

4. **联合评测指标。** WAM 综述提出但尚无人实现的两个指标——**Counterfactual Consistency**（动作如何随想象未来的扰动而适应）与 **Foresight-Conditioned Success**（执行轨迹是否严格遵循生成的视觉计划，而非依赖伪相关）。做出可用实现本身就是高影响力贡献，且 latent 世界模型比像素模型更容易做这类因果探针。

## 10. 值得进一步研究的问题

按重要性与可行性综合排序：

**第一梯队（结构性、且当前无人给出答案）**

1. **世界建模的价值到底在训练梯度还是推理想象？** 2026 H2 的主流设计（WLA / InternVLA-A1.5 / GigaWorld-Policy）都假定是前者并取得 SOTA；但 ω-EVA、World-in-World 的推理时 scaling 发现、WMReward 都指向后者仍有独立价值。**这个张力尚未被任何一篇工作正面解决**，而它决定了整条研究线的方向。

2. **架构耦合的控制变量对照。** WAM 综述直言 cascaded / joint / 离散 tokenization / 隐式对齐这些方案从未在匹配的规模、数据、评测协议下被系统对照过。EgoWAM 在"世界预测目标"这一个变量上做了典范式的工作，但架构耦合维度仍是空白。

3. **latent-only 表征能否维持与生成式方法同等的接地质量？**（WAM 综述标记的 "vital open question"）与之相关的是 §3.3 里的**表面矛盾**：为什么语义 latent 在控制上更优、生成式预训练在感知上更优？把两者放进同一实验框架是明确的缺口。

4. **数据配比的信息论刻画。** HumanScale 发现第一视角数据能超过真机数据（同等数据量下验证损失低 24%），但也把关键因素推给了"精心设计的过滤与标注流水线"。人类视频的价值究竟是语义的还是动力学的？三层知识（物理先验 / 因果动力学 / 任务逻辑）各自的边际贡献如何随规模和域差变化？

**第二梯队（有明确抓手）**

5. **物理正确性的可微/可验证注入。** 目前主流是数据驱动 + 定向监督（PhysisForcing）+ RL 对齐（WMReward）；显式规则（可微物理引擎、守恒律、接触约束）在具身场景的性价比尚未被认真评估。立场论文 2606.06556 明确点名"世界模型接口必须理解 3D 几何、接触力学和动力学"。

6. **多模态物理状态表征**（触觉、力、声学、材料柔顺性）与 modality-adaptive prediction。

7. **长时程与时间抽象。** WAM 综述给出三条路径：模块化层级（VLM 规划 + WAM 执行）、内生层级 WAM（多分辨率预测）、时间上下文规模化。DexWorldModel 的 O(1) TTT 记忆与 LingBot-World 2.0 的无界交互时长是这个方向的最新尝试。三条路径是否收敛为统一的端到端可学层级，是基础性问题。

8. **实时性：50Hz 的 WAM 是否可能？** 以及前置问题——下游控制真正需要多少预测保真度？GigaWorld-Policy-0.5 的 85 ms（≈12Hz）是目前公开的最好结果之一，距 50Hz 仍有约 4× 差距。

**第三梯队（重要但门槛高）**

9. **联合评测：因果一致性指标。** Counterfactual Consistency 与 Foresight-Conditioned Success 的可用实现 + 社区共享基准。

10. **仿真鲁棒性 → 真机鲁棒性的迁移是否成立？** LIBERO-Plus / RoboTwin-Plus 上的扰动鲁棒性结论在真机上有多大预测力？这批文献里没人系统验证过，但它决定了整个仿真评测体系的可信度。RoboDojo 的 sim-real 统一设计提供了做这件事的载体。

11. **世界模型作为 RL 模拟器时的幻觉控制。** WoVR 给出了第一套系统方案（Keyframe-Initialized Rollouts + WM-策略协同演化），但"如何量化想象轨迹的可信度、并据此加权学习信号"仍是开放的。

12. **prediction-integrated safety。** 用世界预测的不确定性作为安全监控器的一等输入，在执行前验证动作。WAM 综述指出这里存在"二重性"：使 WAM 比反应式策略更强的预测能力，同时也使其失效模式后果更严重——自信地想象了错误的物理未来，可能导致模型提交一长串难以中断或恢复的动作序列。

13. **世界模型的 scaling law。** World-in-World 给出具身场景下第一个数据 scaling law；Lumo-2 声称其模态预对齐"induces 更好的 scaling properties"；GenCeption 展示初步数据 scaling。但模型规模、数据规模、推理计算三者的联合 scaling 尚无系统刻画。

14. **AutoResearch 式的自动化设计搜索。** GigaWorld-Policy-0.5 首次在这个领域用 agent pipeline 系统搜索训练配置。世界模型的设计空间大、消融昂贵，这可能是加速领域进展的元方法。

## 一句话总结

这批文献显示的核心转折是：**世界模型正在从"生成好看的未来"转向"生成对动作有用的未来"**。latent / WAM 路线的价值目前有四条被实证支持——效率（数量级延迟优势）、受控消融下世界预测目标的优越性（EgoWAM：DINO 使 OOD 泛化 +4×）、策略相关的表征质量（语义 latent 全面优于重建 latent）、跨具身可迁移（action-free 预训练可竞争 π0）；但其接地质量能否匹敌生成式方法、以及世界建模的收益究竟来自训练梯度还是推理想象，仍是决定这条路线上限的两个未决问题——而 2026 年 7 月的最新一批工作已经用"训练时建模、推理时只解码动作"的设计对后者投下了赌注。
