# Examples

## Export LeRobot map

Source:

`~/.cursor/projects/home-sany-Documents-Foundation/canvases/lerobot-architecture-map.canvas.tsx`

Outputs:

- `qihao-huang.github.io/canvases/lerobot-architecture-map.html`
- catalog entry `id: lerobot-architecture-map`
- homepage Canvas tab lists it via `catalog.json`

Public URL after push:

`https://qihao-huang.github.io/canvases/lerobot-architecture-map.html`

## Add a second canvas

1. Export `canvases/my-topic.html`
2. Prepend to `catalog.json`
3. No `index.html` change needed if Canvas tab already exists
